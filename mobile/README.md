# React Native Mobile Client

Offline-First Student Mobile Application for the SaaS Learning & Exit Exam Platform.

- **Stack**: React Native, TypeScript, Expo, SQLCipher (13-table offline database).
- **Scope**: Screens MOB-01 through MOB-30 covering offline reading, encrypted exam execution, sync queue, and mastery tracking.
- **Constraints**: Tested on physical Android device via ADB/`scrcpy`.
